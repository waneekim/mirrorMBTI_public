# Mirror MBTI

**내가 생각하는 나**와 **타인에게 읽히는 나**의 차이를 보여주는 모바일 웹앱입니다.
표정 7개와 짧은 문장 낭독 6개를 촬영하면, 그 표정이 다른 사람에게 어떤 감정으로 **읽힐 수 있는지**를 분석합니다.

👉 **폰으로 열기: https://waneekim.github.io/mirrorMBTI_public/**

## 개인정보
- 영상과 음성은 **내 폰(브라우저) 안에만** 저장됩니다. 서버로 업로드되지 않습니다.
- 표정 분석(MediaPipe)도 폰 안에서 실행됩니다.
- 화면 상단 **세션 삭제** 버튼으로 언제든 전부 지울 수 있습니다.

## 이 앱이 하지 않는 것
- "진짜 성격"을 판정하지 않습니다. 보여주는 것은 **인상(어떻게 읽힐 수 있는지)** 입니다.
- 얼굴형·이목구비로 성격을 추측하거나 외모를 평가하지 않습니다.

## 진행 상황
| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 녹화 스튜디오 (표정 7 + 낭독 6 클립) | ✅ |
| 2 | 표정 분석 + 실시간 오버레이 | ✅ (튜닝 중) |
| 3 | 음성(말투) 분석 | ⏳ |
| 4 | MBTI 자기평가 설문 + 리포트 | ⏳ |
| 5 | 인상 서술 + 결과 내보내기 | ⏳ |

## 개발

```bash
npm install
npm run dev          # http://localhost:5173
npm run dev:phone    # 같은 Wi-Fi의 폰에서 접속 (자체 서명 HTTPS)
npm test
npm run build
```

`main`에 푸시하면 GitHub Actions가 테스트·빌드 후 GitHub Pages로 배포합니다.
설계 원칙은 [`CLAUDE.md`](./CLAUDE.md), 작업 목록은 [`ISSUES.md`](./ISSUES.md) 참고.
